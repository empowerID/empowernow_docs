# Methodology (2025 Reassessment)

## Scope
- Compare CRUDService, n8n, and AIService across: visual design, integrations breadth, IAM depth, AI/agents, security/compliance, observability, performance, and ease of use.

## Evidence Sources
- Code citations from CRUDService visual designer, agents, and MCP loopback modules
- Frontend SPA source for node palette, agents, prompts/tools integration
- Compose/env for MCP rate limits, scopes, router flags
- n8n public updates (AI/UX/integrations) via official blog overview (2024 in review)

## Scoring
- 1–10 scale per category; normalized against domain expectations
- CRUDService scores increased where visual designer, agents, and MCP loopback directly impact usability and AI readiness
- n8n breadth score remains highest; AI and UX modestly increased per 2024–2025 updates

## Process
- Read current code to validate features
- Update comparisons and addendums across existing analysis docs
- Provide an executive brief and scorecard for stakeholders

## Limitations
- n8n enterprise feature specifics evolve; point updates may change exact capabilities
- Scores are directional; organizations should pilot with their own workflows and constraints

## Next Steps
- Maintain this methodology alongside future releases
- Update scores quarterly or after major feature drops
