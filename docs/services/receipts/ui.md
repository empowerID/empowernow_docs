# UI — Rendering Diffs and Timeline

## Diff renderer
- Plan diff: JSON Patch on planned vs executed step; highlight add/remove/modify
- Data diff: table/JSON change viewer with inline redlines
- Budget diff: intended vs actual; show constraints triggered and settle amounts

## Accessibility
- Use semantic headings, roles for tabs, and visible focus states
- Provide textual summaries of diffs for screen readers

## Timeline
- Horizontal timeline of steps with icons for Permit/Deny and constraints
- Link each step to its receipt; link head anchor proof
