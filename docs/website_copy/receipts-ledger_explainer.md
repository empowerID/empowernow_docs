# Receipts Ledger — Explainer (Website Copy Aid)

A hash‑chained “receipt ledger” with visual diffs of agent plans and outcomes—so every action is tamper‑evident, human‑auditable, and easy to explain.

- Receipt: signed record per step (who/what/when/why/budget/result)
- Hash chain: tamper‑evident timeline via `prev_hash`
- Diffs: plan/data/budget redlines
- Anchoring: periodically commit head hash (S3/Notary/L2)

Docs deep dives: `services/receipts/index.md`, `services/receipts/quickstart.md`, `services/receipts/api.md`, `services/receipts/storage.md`.
